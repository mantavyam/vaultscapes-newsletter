Kimi drops 2.8T-parameter model with 6.3x faster decoding, beats Claude and GPT-5
45,351 Likes

Moonshot AI just dropped Kimi K3, and it's a big one. This is the largest open-weight model ever announced, sitting at 2.8 trillion parameters with a 1 million token context window. That context window means you can feed it entire codebases, massive documents, or hours of conversation without it forgetting anything.

So what makes it fast at that scale? The new Kimi Delta Attention architecture delivers 6.3x faster decoding at million-token lengths. Think of it like a smarter filing system: instead of re-reading everything each time, it only processes what changed. The model also only activates 16 out of 896 internal "expert" sub-networks per request, keeping compute lean.

Here's what it can actually do:

  • Write, run, and fix code by looking at live screenshots of the output
  • Beat Claude Opus 4.8 and GPT-5.5 on coding and agent benchmarks
  • Reach #1 on Frontend Code Arena with a 76% win rate
  • Handle long multi-step tasks without losing context

You can use it now via the Kimi API or Kimi Code. Open weights drop by July 27.

China open-sources a real-time 3D scene reconstruction model that runs at 20 FPS
11,861 Likes

Point your phone at a room. Walk around. Watch a full 3D map build itself in real time. That's LingBot-Map, a new open-source model from a Chinese research team.

Before this, turning video into 3D required expensive LiDAR sensors or slow processing that took minutes per scene. LingBot-Map skips all that. It reads a regular video stream and outputs 3D geometry on the fly, no special hardware needed.

Here's what it can do:

  • Runs at ~20 FPS on a single GPU, fast enough to feel live
  • Stays stable over 10,000+ frames without drifting or falling apart
  • Works on drone footage, driving videos, and indoor walkthroughs
  • Beats traditional optimization-based methods on benchmarks

This opens up real use cases: robots that map spaces as they move, AR apps that understand room geometry instantly, or autonomous vehicles building live maps without expensive sensors.

It's fully open source on GitHub under Apache 2.0. Get started with one command: 

python demo.py --model_path /path/to/model --image_folder example/courthouse

Claude Code artifacts now pull live data via MCP connectors on demand
10,103 Likes

Claude Code just got a serious upgrade. You can now build dashboards and apps that pull live data on demand, instead of being frozen snapshots.

Here's the idea: you build an artifact once inside Claude Code. That artifact connects to MCP connectors (think of them as plugins that let apps talk to external tools and data sources). Every time someone opens it, it fetches fresh, real-time data automatically.

The clever part? Each viewer uses their own MCP connection. So you see your data, your colleague sees theirs. No re-running sessions, no manual refreshes, no sharing data people shouldn't see.

What this opens up:

  • Live dashboards that update per viewer
  • Apps that take actions on behalf of each user
  • Personalized tools built once, used by many

Available on Pro, Max, Team, and Enterprise plans. Not available on publicly-shared artifacts, so keep that in mind before you build.
