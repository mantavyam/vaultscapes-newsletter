OpenAI brings ChatGPT voice control to desktop so you can run agents hands-free
9,984 Likes

You can now talk to your computer and have ChatGPT Voice actually do things for you, right from the desktop app on macOS and Windows.

Here is what makes this different from just talking to a chatbot. It is powered by GPT-Live, which means it can speak, listen, and act all at the same time. No waiting for it to finish talking before you can jump in.

The big unlock is multi-agent control. You can voice-direct multiple AI agents running in parallel across ChatGPT Work and Codex. Think of agents like background workers handling separate tasks. You just narrate what you want done.

  • Start new tasks by speaking, no typing needed
  • Check or steer work happening in other threads mid-conversation
  • On Mac, Appshots lets ChatGPT see your active window for better context
  • Works with Computer Use, local files, and plugins

Available now on Plus, Pro, Business, Edu, and Enterprise plans. Just update the desktop app and open a new voice chat to start.

Anthropic upgrades Claude voice mode with Opus, tool access, and more languages
9,614 Likes

Claude's voice mode just got a real upgrade. Here's what changed and why it matters.

Before this update, every voice request ran through Haiku, Claude's smallest, fastest model. That was fine for quick questions, but it fell apart on anything complex. Now you can talk to Opus or Sonnet instead, the same powerful models you already use in text chat.

The bigger deal? Voice can now reach your connected tools mid-conversation. Things like:

  • Gmail and Google Calendar, so you can reschedule a meeting just by asking out loud
  • Slack, to get a thread summary without touching your keyboard
  • Canva and Notion, to spin up docs from a spoken idea

You can also switch models mid-conversation using the model picker, and flip between voice and text in the same thread without losing context.

Language support is expanding too, including Spanish, French, Hindi, and Japanese, on every plan. To set it up, go to Settings, then General, then Voice, then Language.

It's rolling out now in public beta on mobile, desktop, and web.

Anthropic ships Claude Managed Agents update with effort controls and 500 skills per session
6,954 Likes

Claude Managed Agents just got a solid batch of updates. Here is what changed and why it matters.

The big idea: Managed Agents let you run Claude as an autonomous agent without building your own infrastructure. It handles the agent loop, tool execution, and runtime so you can focus on the actual task.

Here is what is new:

  • Effort controls -- dial down how hard the agent thinks per task. Lower effort means faster responses and lower cost. Great for simple tasks that do not need heavy reasoning.
  • Session seeding -- instead of two separate API calls to create a session then send it context, you can now bundle up to 50 messages directly into the create call.
  • 500 skills per session -- skills are task-specific instruction sets you attach to an agent. You can now stack up to 500 across a session.
  • Webhooks for memory stores and environments, plus event streaming for sub-agents running inside a parent agent.

You can try everything using the official cookbook, or ask Claude Code directly using the built-in claude-api skill.
