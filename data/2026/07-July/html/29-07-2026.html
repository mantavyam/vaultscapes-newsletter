MCP goes stateless in its biggest update yet, unlocking serverless deployment
9,630 Likes

MCP just dropped its biggest update ever. Here is what actually changed and why you should care.

The old MCP required a persistent session between client and server, meaning each user was locked to one specific server instance. Load balancing was basically impossible, and serverless deployments were off the table.

Now MCP is stateless. Every request carries everything it needs, so any server instance can handle any request. You can now deploy behind a standard load balancer, run on serverless platforms like Cloudflare Workers, or scale horizontally without a shared session store.

The big new things you get:

  • Extensions framework: MCP Apps let servers render UI inside a sandboxed iframe, and Tasks handles long-running async operations
  • Enterprise Managed Auth: plug in your existing identity provider to control server access centrally
  • Formal deprecation policy: future changes will not silently break your code

Updated SDKs for Python, TypeScript, Go, and C# are already available. Older clients still interoperate via automatic fallback.

Anthropic's Claude autonomously cracks encryption schemes in under a week
8,248 Likes

Anthropic's unreleased Claude Mythos Preview just did something that years of expert human review could not: it found real mathematical cracks in two encryption systems used to keep data secure online.

Here's what it cracked:

  • HAWK is a next-gen digital signature scheme built to survive future quantum computers. It passed two years of expert review. Mythos found a hidden mathematical shortcut in 60 hours, cutting its effective security strength in half.
  • AES is the encryption standard securing most internet traffic. Mythos found a way to speed up attacks on a research version of it by 200-800x, autonomously inventing a technique it named the "Mobius Bridge."

Neither breaks anything in production today. HAWK is not deployed yet, and the AES attack only hits a weaker research variant, not the real thing.

The bigger story: Mythos did most of this work on its own, with minimal human input. Each result cost roughly $100,000 in API usage. This opens up AI as a serious tool for stress-testing encryption before it gets deployed at scale.
