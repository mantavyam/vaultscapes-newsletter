Anthropic brings back Claude's Fable 5 model after US government security review
69,152 Likes

Fable 5 is back. After nearly three weeks offline due to US government export controls, Anthropic has redeployed its most capable public model with updated cybersecurity safeguards.

Here is what happened: Amazon researchers found a method of bypassing Fable 5's safeguards, prompting it to identify software vulnerabilities. The government pulled the model. Anthropic then trained an improved safety classifier that targets and blocks the behavior described in the report. Think of a classifier as an automated watchdog that scans every request before Fable 5 sees it.

The tradeoff? The new classifier flags benign requests more often during routine coding and debugging tasks. When that happens, you get Opus 4.8 instead, with a visible notice. Use /feedback in Claude Code to report false positives.

  • Fable 5 is live on Claude.ai, Claude Code, and Cowork
  • Paid plans get Fable 5 for up to 50% of weekly usage limits, then it moves to usage credits
  • The new classifier blocks the reported jailbreak in over 99% of cases

Your regular coding work is mostly unaffected. Anthropic is actively tuning the classifiers to cut false positives.

Anthropic ships Claude Sonnet 5 with near Opus-level reasoning at lower cost
50,503 Likes

Anthropic just shipped Claude Sonnet 5, and the big story is simple: you now get near-flagship performance without paying flagship prices.

Until now, serious agentic work (where the AI plans, uses tools, and runs tasks on its own without you babysitting it) required the bigger, pricier Opus models. Sonnet 5 can make plans, use tools like browsers and terminals, and run autonomously at a level that just a few months ago required larger and more expensive models.

Here's what's actually new:

  • Self-checks its own work without being asked, and finishes complex tasks where previous Sonnets stopped short.
  • Benchmarks land close to Opus 4.8, scoring 63.2% vs 69.2% on agentic coding, at roughly 40% of Opus's standard price.
  • Carries a 1 million token context window and a 128,000 token output limit.
  • Introductory pricing of $2/$10 per million tokens through August 31, then moves to $3/$15.

You can start using it today via claude-sonnet-5 on the Claude API. It's also the new default on Free and Pro plans.

Anthropic ships five new Claude Managed Agents features including per-session config overrides
3,275 Likes

Claude Managed Agents just got a solid batch of updates that make building production-ready AI agents a lot less painful.

Here's what's new and why it matters:

  • Agent Overrides let you start a session from a saved agent config and swap out the model, system prompt, or tools for just that one session. No more duplicating agents for every small variation.
  • Streaming session event deltas means you get real-time updates as your agent works, so you can react to what's happening instead of waiting for it to finish.
  • New webhook event types let your server get notified when a session changes state, so you can drop the long-lived HTTP connection that breaks on restarts.
  • Credential injection scoping keeps each user's API tokens separate and secure, which matters when you're running agents on behalf of multiple users.
  • A new Observability tab in Console shows per-session token usage and tool calls, so you can actually debug what your agent did.

To explore these features, run /claude-api managed-agents-onboard in Claude Code for a guided walkthrough, or check the claude-cookbooks repo on GitHub.
