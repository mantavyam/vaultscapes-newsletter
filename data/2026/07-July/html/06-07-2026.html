Dev turns a reMarkable tablet into a Harry Potter-style AI diary
15,314 Likes

Riddle turns a reMarkable Paper Pro tablet into Tom Riddle's diary from Harry Potter. You write with your pen, your words fade into the page, and an AI writes back in flowing handwriting, stroke by stroke. No screen, no keyboard, no chat box. Just ink on paper.

Here is what makes it tick:

  • After a 2.8-second pause, your handwriting gets sent as an image to a vision AI model (one that can read images), which reads it and replies
  • Works with any OpenAI-compatible API: OpenAI, Groq, OpenRouter, or even a local model
  • First reply appears in roughly 0.9 to 1.1 seconds, streaming sentence by sentence
  • Built in Rust, runs natively on the tablet

To try it, you need a reMarkable Paper Pro with SSH access enabled. Grab the prebuilt zip from the GitHub releases, copy it over with scp, drop in your API key, and tap launch. Still early, but fully open source under MIT.

Open-source tool uses Claude to auto-apply for jobs, hits 3.5k GitHub stars
7,000 Likes

Someone built a Claude agent to apply for jobs. And then open-sourced it. Meet ai-job-search, built by Mads Lorentzen, a PhD geophysicist who automated his own job hunt.

The idea is simple: you fill in your background once, point it at a job posting, and it handles everything. Here is what it does for you:

  • Reads the posting and scores how well you fit the role
  • Drafts a tailored CV, picking only your relevant experience
  • Writes a cover letter framed around what you bring to that specific role
  • A second AI agent reviews the first one's work, flags weaknesses, and the first agent revises
  • Compiles both into clean PDFs ready to send

To get started: fork the repo, run gh repo fork MadsLorentzen/ai-job-search --clone, add your profile, and fire away. You need an Anthropic API key or Claude Pro subscription plus Python 3.10+.

It hit 4.4k stars fast. MIT license. Every step is plain text you can read and change.

Hack cuts Claude Code costs 70% by feeding context as images to OCR
4,844 Likes

pxpipe is a local proxy that cuts your Claude Code API bill by converting bulky text context into images before sending it to the model. Here is the core trick: images are priced by pixel size, not by how much text is packed inside. Dense code and JSON fits roughly 3x more content per token as an image than as plain text.

The result? A real 59-70% cost reduction end-to-end on production traffic. Try it in 30 seconds:

  • Run npx pxpipe-proxy to start the proxy locally
  • Point Claude Code at it: ANTHROPIC_BASE_URL=http://127.0.0.1:47821 claude
  • A dashboard shows live token savings and every text-to-image conversion

But here is the catch you need to know: it is lossy. Exact strings like IDs, hashes, and secrets can be silently misread. Fable 5 reads hex strings correctly 13 out of 15 times. Opus gets 0 out of 15. Keep byte-sensitive values as text, which pxpipe does automatically for recent turns.
