Cursor's agent team rebuilt SQLite in Rust from its 835-page manual, passing 100% of tests
9,790 Likes

Cursor gave a swarm of AI agents an 835-page SQLite manual and said: build this from scratch in Rust. No source code. No internet. No test suite. Just the docs.

The result? A fully working database that passed 100% of a hidden test suite it had never seen. That is not a small thing.

Here is how it works. The swarm splits into two roles:

  • Planner agents use smart, expensive models to break the big goal into smaller tasks and delegate them.
  • Worker agents use faster, cheaper models to actually write the code.

This split matters because a single agent trying to hold the whole project in its head eventually loses track. Splitting the roles keeps each agent focused.

The big money insight: every model combo hit similar quality, but costs swung 15x, from $1,339 to $10,565. Using a frontier model only for planning, and a cheap model for the actual coding, slashed worker costs from $9,373 down to $411. You can explore the output yourself at github.com/anysphere/minisqlite.

Baidu releases free open-source OCR model that reads 100-page PDFs in one pass
2,224 Likes

OCR (Optical Character Recognition, turning scanned documents into text) has always been painful. You split PDFs into chunks, process each page, stitch it back together. Baidu just killed that workflow.

Unlimited-OCR reads an entire multi-page PDF in a single pass. No splitting. No stitching. One call, done.

Here is what makes it actually usable:

  • 3 billion parameters, runs on a single mid-range NVIDIA GPU, no beefy server needed
  • Handles multi-language documents without extra setup, outperforms DeepSeek-OCR on standard benchmarks
  • 32,768-token output window, so even 100-page contracts fit in one shot
  • Plugs into Transformers, vLLM, or SGLang, tools you already know
  • MIT license, free weights on Hugging Face, zero API costs

Cloud OCR bills you per page. This runs locally, forever, for free. You can drop it into any data pipeline to extract text from contracts, papers, or scanned archives without touching a paid API. 15,000+ GitHub stars already.
