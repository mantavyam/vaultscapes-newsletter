OpenAI quietly ships open-source security CLI to scan repos and catch vulnerabilities in CI/CD
13,652 Likes

OpenAI tried to quietly ship Codex Security CLI, but Hacker News spotted it first. Classic.

So what is it? It's a free, open-source tool that uses AI to automatically find security holes in your code, confirm they're real, and suggest fixes. Unlike old-school scanners that just match patterns, it uses AI to understand how your code actually behaves in context, then proposes patches you can review and apply.

Here's what you can do with it:

  • Scan entire repos for vulnerabilities
  • Track findings across multiple runs to see if fixes actually worked
  • Review pull-request diffs and get structured output for security automation
  • Plug into CI/CD pipelines using an API key, no interactive login needed

Getting started takes three commands: install, login, scan. Basic usage is free, but an OpenAI API key unlocks full scanning and is the preferred path for automated setups.

The tool has already helped fix over 3,000 critical vulnerabilities, and it's Apache 2.0 licensed, so you can use it freely in your projects.

Fish Audio raises $52M and ships a voice model 2x faster than rivals
13,215 Likes

Fish Audio just launched S2.1 Pro, a voice AI model that went from open-source side project to $21M ARR in one year, and just raised a $52M seed round to back it up.

So what actually makes it interesting? Three things:

  • 5-second voice cloning -- drop in a short audio clip and it captures tone, pitch, and speaking style instantly, no retraining needed
  • Word-level emotion control -- you can tell it exactly how to say each word: the pacing, intonation, and emotion, not just the whole sentence
  • ~90ms response time -- fast enough for real-time voice agents and live conversation apps

It runs at 2x the speed of Cartesia and roughly 1/6th the cost of ElevenLabs. HeyGen, LiveKit, and Retell already run it in production.

You can access it via REST API or Python SDK. There is also a free tier with no hard usage cap, so you can prototype without a paywall blocking you.

OpenAI gives 100,000 academic scientists free access to GPT-5 models by 2027
7,931 Likes

OpenAI just launched ChatGPT for Academic Researchers, a free program giving scientists access to its most powerful models. Starting with 10,000 seats this summer and scaling to 100,000 by 2027.

Here is what you actually get:

  • GPT-5.6 Sol Pro, the flagship model, which scores 83% on research-level math benchmarks vs. 72.5% for the previous version
  • Access to Codex for writing and running code, plus ChatGPT Work for longer multi-step tasks like drafting papers or grant applications
  • Higher usage limits, larger context windows, and expanded deep research mode
  • Up to 4 collaborators per workspace, with business-grade privacy and your data never used for training

The value is roughly a $200/month Pro subscription at zero cost. Faculty and postdoctoral researchers at high-research-activity institutions can apply now on OpenAI's website. This is part of a $250 million commitment to external science through 2027.
