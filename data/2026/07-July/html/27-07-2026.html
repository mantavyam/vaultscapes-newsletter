Claude Opus 5 builds a complete game from scratch in one shot
6,652 Likes

Someone gave Claude Opus 5 a single prompt asking it to build a first-person shooter at Call of Duty quality. It produced a 55,000-line game in one shot, using Three.js in the browser. No art assets, no sound files, no external libraries. Everything, textures, physics, audio, was generated from code at load time.

Here is what the AI built from scratch:

  • 11 full subsystems: rendering, physics, AI soldiers, weapons, audio, UI, and more
  • A physics engine written from zero, no library, with ragdoll deaths and bullet penetration
  • Web Audio synthesis, meaning all sounds are computed, not loaded from files
  • A 120x120m playable map with enterable buildings and hundreds of props

Honest caveat: critics scored it 5 out of 10 against real Call of Duty frames. It looks procedural up close. But the repo is public, the prompt is included, and you can run it yourself with npm install and npm run dev. What this opens up is the ability to prototype entire interactive experiences from a description alone.

OpenAI's ChatGPT Work agent can now log into password-protected websites
4,339 Likes

The ChatGPT Work agent just got a lot more useful. It can now access websites that require a login, which was the biggest wall stopping it from doing real work on your behalf.

Here is how it works. When the agent hits a login page, it pauses and hands control to you. You log in manually, then pass control back. From that point, the agent picks up exactly where it left off and keeps going on its own.

The best part: your login persists across sessions, so you only do this once per site. Cookies stick around just like in a normal browser.

On the security side, when you take over the browser to type your password, the agent sees nothing. No screenshots are captured, no credentials are stored.

  • You can now automate tasks on tools like Jira, Notion, or internal dashboards
  • Clear saved logins anytime in ChatGPT data settings
  • Avoid vague prompts like "handle everything" to stay in control

This opens up real end-to-end automation for any site behind a login wall.
