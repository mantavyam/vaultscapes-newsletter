Anthropic's Claude agent trick hits 96% top model performance at half the cost
19,437 Likes

Fable 5 is Anthropic's most powerful model, but it's also the priciest. Running everything through it is a fast way to burn your budget. So Anthropic shared two smart patterns to get near-Fable quality at a fraction of the cost.

Pattern 1: Fable as Advisor. Sonnet 5 does all the heavy lifting. It only calls Fable 5 once per task when it needs guidance. Result? 92% of Fable's performance at 63% of the cost on coding benchmarks.

Pattern 2: Fable as Orchestrator. Fable plans the task and breaks it into pieces. Sonnet 5 workers execute each piece. Most tokens are billed at the cheaper Sonnet rate. On research tasks, this hit 96% of Fable's performance at 46% of the cost.

Both patterns are supported natively in Claude Managed Agents. Each sub-agent keeps its own cache, so repeated context isn't paid for twice. You can set this up by pinning models in subagent definitions using the model field in Claude Code.

This opens up running complex, multi-step AI pipelines at production scale without the frontier model bill.

Anthropic brings Claude background tasks to mobile so work continues without you
16,654 Likes

Claude Cowork just went cross-device. It used to live only on your desktop. Now it runs on web and mobile too, meaning tasks you kick off at your desk keep running after you close your laptop.

Here is what actually changes for you:

  • Tasks run without you. Close the laptop, Claude keeps going. No device needs to stay online.
  • Scheduled tasks work overnight. Set a 6am client brief, and Claude pulls email threads, builds the doc, and leaves a draft ready for your review.
  • When Claude hits a decision only you can make, it pings your phone instead of stopping.
  • Chat and Cowork now share one tab on web and desktop, so your projects and files live in one place.
  • Doubled usage limits are extended through August 5, so you can throw bigger tasks at it.

Beta rolls out to Max plan first. To try it, just start a task the same way you start a conversation.

If you maintain an open source project, Anthropic just handed you something real. Claude for Open Source gives qualifying maintainers six months of free Claude Max 20x, which normally runs $200/month ($1,200 total value).

So what is Max 20x exactly? Think of it as 20 times more usage than the standard $20 Pro plan. You stop hitting that wall mid-afternoon where Claude says "slow down." You get priority access during peak hours, full Claude Code access in your terminal, and roughly 900 messages per session window.

What does this actually unlock for you?

  • Run full agentic refactoring loops across large repos without getting cut off
  • Review and triage issues at scale using Extended Thinking mode
  • Keep Claude Code running all day without rationing prompts

To qualify, your project needs 5,000+ GitHub stars or 1M+ monthly npm downloads, with recent commits or PR activity. Maintainers, core contributors, and anyone keeping a critical package alive are all eligible. Apply at claude.com/contact-sales/claude-for-oss. Note: this does not include API access.
