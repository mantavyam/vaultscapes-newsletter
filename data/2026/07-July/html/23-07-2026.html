Anthropic ships Claude Code security plugin that scans your code for vulnerabilities
11,838 Likes

Anthropic just dropped the Claude Security plugin for Claude Code in beta, and it's worth paying attention to.

Here's the problem it solves: AI writes code fast, but fast also means security holes sneak in faster. Think SQL injection, hardcoded secrets, unsafe function calls. They slip through before anyone notices.

This plugin sits inside your terminal and catches those issues before they become your problem. The cool part? No extra commands to remember. It runs automatically as you code.

It works in three layers:

  • Every file edit triggers an instant pattern scan, flagging dangerous stuff like eval(), os.system(), and innerHTML with zero extra cost
  • After each coding turn, a separate Claude model reviews your full git diff for logic-level flaws like auth bypasses and insecure references
  • At commit time, it does a deep cross-file review to catch issues that only show up in context

It's free for all Claude Code users. Install it with /plugins in your terminal, then run /reload-plugins. Done.

Cursor ships smart model router that cuts AI coding costs by 60%
8,803 Likes

You know how you always have to pick which AI model to use in Cursor? Too powerful and you burn budget. Too cheap and the output suffers. Cursor Router just killed that tradeoff.

Here is how it works: instead of you picking a model, Cursor analyzes each request and picks for you. Simple autocomplete? Cheap model. Complex refactor? Frontier model. You stop thinking about it.

You get three modes to tune the behavior:

  • Intelligence: best quality, still cheaper than always using top models
  • Balance: solid quality at around 36% lower cost
  • Cost: maximum savings for lighter tasks

In early testing, teams with thousands of users saved 30-50% with no drop in quality versus routing everything to Opus 4.8. Cost per commit dropped too, which is the number that actually matters.

It is live now on Teams and Enterprise plans. Admins can control which models are allowed, set defaults per team, and lock certain modes. Auto mode is now powered by Router out of the box.

Anthropic ships effort controls, 500 skills, and webhooks to Claude Managed Agents
3,768 Likes

Claude Managed Agents just got a solid set of updates that make building multi-agent systems a lot less painful.

The biggest quality-of-life fix: you used to need separate API calls to create a session and send it events. Now you can seed a session with up to 50 events in a single create call, cutting setup time and complexity.

  • Effort levels per agent -- control how hard each agent thinks. Lower effort means faster, cheaper responses. Higher effort means more thorough work.
  • 500 skills per session -- skills are task-specific instructions you give an agent. You can now stack up to 500 across all agents in one session.
  • Webhooks for environments and memory stores -- get notified when things happen in the background, so you can trigger other actions automatically.
  • Sub-agent event streaming -- watch what your child agents are doing in real time.

Together, these let you build smarter pipelines where different agents handle different tasks at different cost levels. Try it via the claude-cookbooks repo on GitHub.
