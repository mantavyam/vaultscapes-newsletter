Meta releases open-source brain-to-text decoder hitting 78% word accuracy
12,736 Likes

Your brain is basically a noisy electrical storm. Getting useful language out of that chaos is really hard. That's exactly what Brain2Qwerty v2 tackles.

Researchers trained it on 22,000 sentences from 9 volunteers, each wearing an MEG device (a helmet that reads magnetic signals from your brain) while typing for 10 hours. The system watches those brain signals and tries to figure out what words you intended to type.

  • 61% average word accuracy across all participants
  • 78% word accuracy for the top participant
  • 50%+ of sentences decoded with one word error or less
  • Performance improves as you feed it more data

The big jump from v1: it now decodes whole words and meaning, not just individual characters. It combines deep learning on raw brain signals with fine-tuned language models to clean up the noise.

The full training code for both versions is now public, so you can build on it directly.

Cursor ships iOS app so you can run and control coding agents from your phone
11,309 Likes

Your laptop no longer needs to be open for code to get written. Cursor just launched a native iOS app, and it flips what a mobile coding tool even means.

It is not a tiny code editor on your phone. It is a control center for AI agents doing the work while you are away from your desk.

Here is what you can actually do:

  • Pick a repo, describe a task by voice or slash command, and launch a cloud agent that keeps running even with your laptop closed
  • Use Remote Control to steer agents already running on your local machine, straight from your phone
  • Get lock screen Live Activity updates when an agent finishes or needs your input
  • Review diffs and merge PRs directly from the app

Cloud agents run inside isolated virtual machines, so they can test and verify their own work. You can also hand off a session from local to cloud mid-task, then pull it back before merging.

Available now in public beta on all paid plans, with 75% off Composer 2.5 runs in the app.

10 open-source GitHub tools that scrape any website for free
5,241 Likes

Web scraping used to mean paying $2,000/month for enterprise tools or begging for API access. That era is over. A viral thread just mapped out 10 open-source repos that give you the same power for free.

Here is what the stack covers:

  • Firecrawl - Point it at any site, it crawls every page, renders JavaScript, and returns clean structured data your AI can read instantly. 130k stars.
  • browser-use - An AI agent that controls a real browser like a human. Clicks, scrolls, logs in, fills forms. Built by two ETH Zurich researchers, now at 100k stars. Reaches pages simple scrapers cannot.
  • Crawl4AI - Converts any site to clean markdown ready for LLMs. No API keys, no accounts, no per-page fees. Apache 2.0.
  • Microsoft MarkItDown - Converts PDFs, Office docs, and images into clean markdown. Entire data pipelines are built around this.
  • Crawlee - Full scraping framework with proxy rotation, auto-retries, and anti-detection built in. The stack scraping companies charge thousands for.

Together these let you build AI training datasets and RAG pipelines without touching a paid API.
