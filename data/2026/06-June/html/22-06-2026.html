UC Berkeley releases 2.2 million U.S. local laws as a searchable open dataset
6,534 Likes

Local laws are technically public. But they were buried in PDFs across thousands of city websites, impossible to search or use in code. That was the problem.

Researchers just fixed it. LOCUS is a dataset of 2.2 million U.S. local laws scraped from 9,239 cities and counties, covering zoning, housing, noise, business licensing, and more. It covers the majority of the U.S. population.

To handle all the messy PDF formats, they ran everything through LightOnOCR-2-1B, a small AI model that reads document images and outputs clean text. All 7 million pages, processed at $0.30 per 1,000 pages vs. $1.50 on AWS Textract.

They also trained classifiers to score each law on four axes:

  • Paternalism: how much it controls behavior
  • Opacity: how hard it is to understand
  • Enforcement discretion: how much leeway officials get
  • Salience: how much it actually matters

You can grab the dataset and models on Hugging Face under LocalLaws/LOCUS-v1 to build legal search tools, compliance checkers, or policy analysis apps.

Nous Research ships blank slate mode so you can build agents from scratch
3,025 Likes

Hermes Agent just added a third setup mode called Blank Slate, and it flips the usual approach on its head.

Most agent tools dump everything on you by default. Blank Slate does the opposite. You start with just a provider, a model, file operations, and a terminal. Everything else, including web, browser, code execution, vision, memory, and MCP servers, starts off.

The big deal here is control that actually sticks. Nothing you did not choose ever loads, not even after hermes update. No surprise tools sneaking back in after an upgrade.

What this opens up:

  • Security-sensitive setups where you want zero network access unless you explicitly add it.
  • Reproducible team configs where every machine runs the exact same toolset and updates never drift it.
  • Add things back anytime with hermes tools, hermes skills opt-in --sync, or hermes setup agent.

To try it: run hermes setup and pick Blank Slate. Build up from there.

Nous Research ships Hermes Agent v0.17.0 with expanded reach capabilities
2,943 Likes

Hermes Agent just dropped v0.17.0, and the theme is simple: reach. Last version put it on your desktop. This one asks how far it can actually go.

The answer? Pretty far. Here is what landed:

  • iMessage support via Photon Spectrum. No Mac relay needed. Run hermes photon login, do a quick OAuth, done.
  • Background subagents. You can now fire off a task and keep chatting. The result drops back into your conversation when it finishes, instead of freezing everything.
  • Automation Blueprints: schedule tasks in plain English. No cron syntax. Just answer a few questions and it sets up the job.
  • Cursor's Composer coding model is now accessible through your xAI Grok subscription, no extra API key.
  • WhatsApp Business Cloud API, Raft agent network support, and a much deeper desktop app.

This release had 1,475 commits and 245 contributors. To get it, just run hermes update.
