OpenAI launches GPT-5.5-Cyber to scan, patch, and fix vulnerable code at scale
3,470 Likes

Security bugs pile up faster than anyone can fix them. OpenAI just shipped a full stack to close that gap.

The centerpiece is GPT-5.5-Cyber, a specialized model that scored 85.6% on CyberGym (vs 81.8% for standard GPT-5.5). It is gated to verified defenders only, not open access.

Plugged into Codex, the new Codex Security plugin lets you run end-to-end security workflows without switching tools:

  • Scan your codebase, trace real attack paths, and build threat models from your repo
  • Validate findings in an isolated environment so you fix real bugs, not noise
  • Generate codebase-specific patches and export results into your existing tools via SARIF and CodeQL

Since its research preview, Codex Security scanned 30 million commits across 30,000+ codebases. That is real scale.

The Patch the Planet initiative brings this to open source. Projects like cURL, Python, and Go are already in. Maintainers get Codex access and API credits to help ship fixes, not just find bugs.

Cursor announces three new features including a model trained with SpaceX
2,992 Likes

Cursor just held Compile, its first-ever user conference, and dropped three big announcements on the same day SpaceX acquired the company for $60 billion.

Here's what was announced:

  • SpaceX acquisition: SpaceX is buying Cursor in an all-stock deal. The goal is building the world's best coding AI, combining Cursor's product with SpaceX's massive Colossus supercomputer cluster.
  • Composer 3 incoming: A brand new model is coming. It has 1.5 trillion parameters (think of parameters as the brain cells of an AI, more means smarter), trained on over 100,000 GPUs from scratch. It sits in the same performance class as Claude Opus and GPT-5.5, but built specifically for coding.
  • Joint model with SpaceX: Cursor and SpaceXAI have already been co-training a model together. It will ship inside both Cursor and Grok Build.

What this opens up: you get a coding assistant backed by rocket-company-scale compute, not just a startup's GPU budget. Smarter completions, better multi-file edits, and intelligence that goes beyond just code.

GLM 5.2 tops open-source coding leaderboard, beating Kimi K2 by 17%
2,786 Likes

GLM-5.2 just claimed the top spot among open-source models on the DeepSWE leaderboard, and the gap is hard to ignore.

First, what is DeepSWE? It is a coding benchmark that drops an AI into an isolated container and asks it to fix real bugs from active open-source repos, no internet, no hints. Think of it as a coding interview that actually reflects your job. The score is pass@1, meaning: did it solve the problem on the first try?

  • 44% pass@1 at max effort on DeepSWE, beating Kimi K2.7 Code by 17%
  • DeepSWE score jumped from 18% to 46.2% vs the previous version
  • 81.0 on Terminal-Bench 2.1, just 4 points behind Claude Opus 4.8
  • MIT license, so you can use, modify, and ship it commercially with no restrictions
  • 1 million token context, meaning you can feed it an entire codebase in one go

This lets you build coding agents that handle real, messy repositories, not just toy problems. You can self-host it, plug it into vLLM or SGLang, and run it on your own infrastructure with zero vendor lock-in.
