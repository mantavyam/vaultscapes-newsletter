Sakana AI ships a multi-agent orchestration model designed to bypass export controls
45,885 Likes

Most AI tools make you pick one model and hope for the best. Sakana Fugu flips that. It is itself a small AI model that has learned to call other AI models, pick the right ones for each step, and stitch the results together automatically.

You hit one API endpoint. Fugu handles everything behind the scenes.

It comes in two versions:

  • Fugu: fast, low-latency, great for coding assistants like Codex and everyday chatbot work. You can also block specific models from its pool for data compliance.
  • Fugu Ultra: the heavy-hitter. Pulls in a deeper pool of expert models for hard tasks like cybersecurity analysis, research, and patent investigations. Matches top frontier models on benchmarks.

The API is OpenAI-compatible, so dropping it into existing projects is straightforward. It hits top scores on SWE-Pro, GPQA-D, and ALE-Bench.

The bigger idea: if one model gets hit by export controls and disappears, Fugu just swaps in another. No code changes on your end.

Anthropic ships Claude as a Slack teammate that writes and merges your code
20,243 Likes

Anthropic just shipped Claude Tag, and it's a pretty different take on AI tooling. Instead of opening a chat window, you just type @Claude in Slack and hand it a task.

Here's what makes it click. Within a channel, there's one Claude that interacts with everyone, so anyone can pick up the conversation from where the last person left off. No more re-explaining context to a fresh chat window.

What you can actually do with it:

  • Tag @Claude with a request, and it breaks the task into stages, executes them, and posts results back in a Slack thread.
  • With ambient mode on, Claude proactively flags relevant info from across channels and follows up on threads that went quiet.
  • It builds context as it follows the channel, so you stop explaining the same background on every request.

The proof point: 65% of Anthropic's product team's code is now created by their internal version. It runs on Opus 4.8 and is available now in beta for Enterprise and Team plans.

Someone ran a real-world test: fix an actual bug from the Cline repo. Two models, same tools, same setup. Who wins?
