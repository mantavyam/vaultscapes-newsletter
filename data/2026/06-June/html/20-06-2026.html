Unsloth shrinks GLM-5.2 by 84% so it runs locally on a 256GB Mac
5,769 Likes

A 1.51TB AI model running on your laptop sounds impossible. It kind of is. But Unsloth just made it a lot less impossible.

GLM-5.2 is Z.ai's newest open model, and it's a big one: 744 billion parameters, MIT licensed, with a 1M token context window (think: entire codebases at once). The catch? The full model weighs 1.51TB. Nobody has that lying around.

Unsloth's fix: quantization. That means shrinking the model by storing numbers less precisely, like compressing a photo. The 2-bit version drops to 238GB, retaining ~82% accuracy. Important layers stay at higher precision so quality doesn't collapse.

What you actually need to run it:

  • A 256GB Mac (M3/M4 Ultra) for single-box setup
  • Or a 24GB GPU plus 256GB RAM with memory offloading
  • Tools: llama.cpp, LM Studio, or Unsloth Studio

This opens up private, offline coding agents and long-context tasks that previously required a cloud API. No usage fees, no rate limits, no data leaving your machine.

AgentDeck plugin turns Stream Deck+ into a Claude Code control panel
5,125 Likes

Tired of tab-switching every time Claude Code needs your input? Someone just turned a Stream Deck+ into a physical control panel for AI coding sessions, and it's exactly as cool as it sounds.

The setup uses AgentDeck, an open-source plugin that hooks into Claude Code's event system. Claude Code fires off signals whenever something happens in your session. AgentDeck catches those signals and pushes live status updates to the physical buttons and dials on your Stream Deck+.

What you can actually do with it:

  • See which sessions are running, waiting for input, idle, or errored, all on physical buttons
  • Approve or deny permission requests with a single button press, no keyboard needed
  • Monitor token usage and session cost per button
  • Manage multiple Claude Code sessions simultaneously from one surface

To try it: grab the repo at github.com/asheshgoplani/agent-deck and run the install script. Currently Stream Deck+ only.

Anthropic study of 400K Claude Code sessions shows task value grew 27% in six months
5,081 Likes

Anthropic just dropped a study on 400,000 Claude Code sessions from 235,000 users, and the findings are worth knowing.

Here's what the data actually shows:

  • You don't need to be a software engineer. Every major occupation succeeded at coding tasks within 7 percentage points of software engineers. Lawyers, finance folks, managers -- all roughly the same success rate.
  • Sessions are getting more valuable. Compared against freelance marketplace rates, the average session grew 27% in monetary value from October to April. People are tackling harder, pricier work.
  • The work split is clear. You handle ~70% of planning decisions. Claude handles ~80% of execution.
  • Expertise still matters. Novices hit verified success 15% of the time. Intermediate and expert users land between 28-33%. The gap between intermediate and expert is small though -- being decent at a domain is enough.
  • Use cases are shifting. Code-fixing sessions dropped from 33% to 19%, while software operation grew from 14% to 21%.

The big takeaway: Claude Code is becoming a tool for anyone with domain knowledge, not just people who can code.
