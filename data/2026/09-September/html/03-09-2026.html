Anthropic open-sources Claude shopping agents that boost cart size by 35%
6,219 Likes

Anthropic just open-sourced Claude Commerce Agents, a ready-to-use blueprint for building AI shopping assistants. Think of it as a starter kit so you skip weeks of figuring out how to wire an AI agent to a store backend.

There are two agents included:

  • Shopping agent: sits inside a customer-facing app, searches products, fills carts, and answers order questions
  • Merchant agent: helps store staff manage listings, inventory, and pricing, but every change waits for a human to approve it
  • Four vertical demos: retail, travel, telecom, and entertainment, all runnable out of the box
  • A Claude Code plugin that scaffolds an agent against your own backend automatically

Real results from pilots: 35% larger carts and shoppers 60% more likely to complete a purchase. To get started, clone the repo, add your API key, and run 

python scripts/run_demo.py retail

Qwen upgrades its 2.4T parameter model with 1M token context at $2 per million
5,733 Likes

Alibaba just pushed an update to Qwen3.8-Max, and the new version is called Qwen3.8-Max-0902. Same giant model underneath, but with extra post-training focused on coding and collaborative work tasks.

Quick recap of what this thing actually is: a 2.4-trillion-parameter model with 95B active parameters and a 1M-token context window. That context window means you can feed it an entire large codebase in one shot.

The upgrade sharpens it for real enterprise work. Here is what it handles well:

  • PaperBench score of 93.0, ahead of GPT-5.6 Sol, Claude Fable 5, and Opus 4.8
  • OSWorld-Verified score of 86.1, beating GPT-5.6 Sol Max and Claude Fable 5
  • Strong vision across satellite imagery, documents, technical drawings, and crowded scenes

Pricing stays the same: $2 per 1M input tokens and $6 per 1M output tokens, plus cache discounts. You can hit it right now via the QwenCloud API.

Google ships Gemini 2.5 Flash with stronger coding and multi-step reasoning at same price
3,949 Likes

Google just dropped Gemini 3.8 Flash, and the pitch is simple: smarter reasoning, same low price as 3.7 Flash.

So what actually changed? The model now works harder on tough tasks. The performance boost comes from a design choice: it executes extra internal reasoning steps and calls tools repeatedly to reach better answers. Think of it like a teammate who keeps double-checking their work instead of stopping at the first answer.

Here is what it is good at:

  • On long-horizon coding, it beats most larger, pricier models at solving complex engineering problems end to end.
  • On Terminal-Bench 2.1, an agentic terminal coding test, it scores 89.4%, edging out Claude Opus 5.
  • It handles text, image, audio, video, and PDF input with a 1M token context window.

Pricing stays at $0.75 per 1M input tokens and $3.75 per 1M output. If you need lower compute overhead, you can adjust effort settings or stay on 3.7 Flash. You can try it now via the Gemini API and AI Studio.
