DeepSeek ships faster open-source model with free search and fetch APIs
35,581 Likes

DeepSeek just dropped V4.1-Flash-1017, a tighter update to their Flash model. Same base, better results across the board. Faster outputs, shorter responses, lower cost. All at once.

Here's what actually changed and why it matters:

  • Coding scores jumped hard: 77.0% on DeepSWE (a coding task benchmark), beating Claude Opus 5 at 74.0% and GPT-5.6 Sol at 73.0%
  • End-to-end project building: the model uses reinforcement learning with self-feedback, meaning it learns from its own mistakes to build full projects, from games to 3D models, without you babysitting every step
  • 1M token context window with up to 256K output tokens, so you can feed it entire codebases
  • Search and Fetch APIs now open: plug DeepSeek's own search engine into your app at $0.75 per 1,000 calls. Free if you use it through Claude Code or Codex right now
  • Weights are MIT-licensed on Hugging Face, run it locally via vLLM or SGLang

Upgrade to DeepSeek Harness v0.2.1-rc.1 to get the best experience. The API model name is deepseek-flash.

Claude Code removes 25 bloatware apps from a Xiaomi TV using just the model number
22,773 Likes

Someone's parents had a Xiaomi TV that forced them to sit through a sponsored ad before reaching Netflix. So they grabbed Claude Code, gave it the TV model, and let it loose.

The AI found the TV over Wi-Fi using ADB (Android's built-in debug tool, basically a remote control for Android devices), stripped 25 bloatware packages, and built a custom home screen from scratch. No root. No cables. Fully reversible.

The result looks like an Apple TV. Here's what you get:

  • Clean black home screen with a 4-app dock at the bottom
  • App grid that slides up on demand
  • Zero sponsored rows, zero analytics phoning home
  • One-line restore if you want to undo everything

Works on any Android TV or Google TV: Xiaomi, TCL, Sony, Hisense, OnePlus. The full prompt, launcher source, and gotchas are open on GitHub with 1.3k stars already.

You can run it yourself in about 15 minutes.
