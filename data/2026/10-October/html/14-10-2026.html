Anthropic built its own version control after AI agents pushed git past 30,000 daily merges
17,736 Likes

Anthropic just ditched Git. The reason: Claude writes code so fast that Git literally could not keep up.

Daily merges grew from 2,500 in May to over 30,000 in September, driven by Claude writing most of the code. Git was built for humans working at human speed. AI agents don't take lunch breaks.

So they built their own system called Scion. The key idea: unlike Git, which is decentralized, Scion assumes the server is always available and clients request only the data they need. That's the opposite of how Git works.

The results:

  • CPU and memory usage dropped by roughly 200x compared to the old Git setup.
  • Code checkout times dropped from minutes to seconds.
  • A team of seven built Scion and a code review tool called Antique, and migrated the monorepo in five months.

Scion is not a general Git replacement. But Anthropic hopes Git platforms adopt the transferable ideas: server-side operations and smarter sparse checkout features.

Fish Audio ships Drama 3, an open-weight voice model with word-level tone control
11,110 Likes

Fish Audio just dropped Drama 3, an open-weight text-to-speech model that lets you direct AI voices like a film director, using plain English instead of clunky code tags.

Most TTS tools give you one flat voice. Drama 3 changes that. You write square-bracket instructions right inside your script, like stage directions, and the model follows them. Start calm, get angry mid-sentence, whisper one word, shout the next.

Here is what it can do:

  • Control tone, pacing, and emotion word-by-word using plain English cues
  • Fix a single word without re-generating the whole audio clip
  • Voice full multi-character scenes in one pass
  • Supports 83 languages with mid-sentence voice and language switches

Under the hood it is a 35B parameter model (only 3B active at a time, so it runs leaner than it sounds) available on Hugging Face. It hits 89ms to first audio on a single H200 GPU. It ranks #1 among open-weight TTS models on the Artificial Analysis leaderboard, beating ElevenLabs on pronunciation accuracy.

You can use it via the Fish Audio API or self-host the weights yourself.

Claude maps 5,285 km of real US roads into a clicker game for under $500
7,108 Likes

Someone built a coast-to-coast USA clicker game using Claude Opus 5.5, and the whole thing cost under $500. That's real roads, real mountains, real buildings, all rendered as pixel art.

Here's how it works: Opus 5.5 pulled 5,285 km of real road data from OpenStreetMap (a free, community-built map of the world), sampled every 10 meters. The mountains you see on the horizon are real too, pulled from elevation grids. The engine figures out what hills are visible by scanning outward and tracking the steepest angle, accounting for the actual curve of the Earth.

The result? 1,185 AI-generated images, including 71 vehicles with animation frames.

You can use it yourself right now as a Claude Code skill:

  • Pick any two locations on Earth
  • Get a price estimate, then choose your quality level (free placeholders up to detailed pixel art)
  • Get a full flyable, walkable route back

Install it with /plugin marketplace add jonwheatley/pixel-path inside Claude Code, then just ask for a pixel path between any two places.
