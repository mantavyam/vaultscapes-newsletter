Anthropic ships Claude Dashboards and Motion to turn data into live charts and animations
31,872 Likes

Claude just shipped two new tools, and they are worth knowing about.

Claude Dashboards connects to data platforms like BigQuery, Snowflake, and Salesforce. You ask a question in plain English, and Claude writes the database query for you, builds a live chart, and keeps it updated as your data changes. No SQL skills needed. Available on all paid plans.

Claude Motion is the fun one. Give it a report or a chart, and it builds a short animation. The trick: it writes the animation as actual editable code, not generated video footage, so you can tweak any word, number, or timing yourself, then export an MP4. Team and Enterprise only.

  • Dashboards: connects to Redshift, BigQuery, Snowflake, Databricks, Salesforce
  • Motion: code-based animations, fully editable, exports as MP4
  • Docs, Slides, and Design are now out of beta and free on all plans, including the Free tier

Over 45 million docs and decks have already been made in Claude. The workspace is getting real.

OpenAI opens Decisions API beta, routing model choices 10x faster than GPT-6 Luna
6,207 Likes

Most AI calls return a wall of text. But sometimes you just need a yes, a category, or a score. That's the gap OpenAI's Decisions API fills.

Instead of generating a full response word by word, it skips straight to a typed answer. That's why it's up to 10x faster than the standard Responses API. Less work, faster result.

You send text or images, ask structured questions, and get back one of three answer types:

  • Predicate: a 0-to-1 probability that something is true (e.g. "Is this image damaged?")
  • Choice: picks from options you define, with a confidence score attached
  • Score: rates input against ordered levels you set

You hit POST /v1/decisions with your input and questions. Pricing is $0.10 per million input tokens, and output tokens are free. It also supports HIPAA and Zero Data Retention, so it works for sensitive pipelines too.

Try it now in public beta using gpt-6-luna.

Anthropic opens Claude to verified security pros for offensive pen testing
5,780 Likes

Anthropic just unlocked Claude for serious security work. The Cyber Verification Program (CVP) now has three tiers, each giving verified teams progressively fewer safety restrictions on Claude's most capable models.

By default, Claude blocks most cyber-related tasks. This program changes that for people who actually need it.

Here's what each tier lets you do:

  • Defense Access: security operations, incident response, malware reverse-engineering, vulnerability validation
  • Red Team Access: authorized penetration testing and offensive simulations. In tests, Claude Opus 5.5 completed 34 of 50 offensive tasks with zero blocks
  • Specialized Access: the highest tier, co-vetted with the US government, for critical infrastructure work

All three tiers include Claude Opus 5.5, Sonnet 5.5, and Mythos 5.1, plus future models. You can apply through the CVP portal and access it via Claude Platform, Google Cloud Vertex AI, or Microsoft Foundry.

The results speak for themselves: Glasswing partners already found 129,000+ verified vulnerabilities, with over 33,000 rated critical or high severity.
