GitHub tool routes Claude Code through 49 free providers, 1.3B tokens monthly
6,399 Likes

You know how Claude Code costs money every month? Someone built a free proxy that routes your requests through 53 free AI providers instead. Same Claude Code interface. Zero subscription cost.

The idea is simple: Claude Code thinks it's talking to Anthropic, but it's actually hitting free providers like DeepSeek, Kimi, Groq, and Gemini. You get 1.3 billion free tokens per month pooled across all of them. If one provider goes down, it auto-switches to the next. No restarts needed.

What you can actually do with it:

  • Run Claude Code, Codex, Cline, Aider, and 6 other coding agents, all from one setup
  • Use it in your terminal, VS Code, JetBrains, or even your phone
  • Send voice notes and get code back using built-in Whisper transcription

Setup takes about 5 minutes. The project already has 55,000+ GitHub stars, so it's well-tested. Worth trying before paying for another subscription.

Z.ai releases GLM-Legal, a model that matches frontier models on legal tasks
5,055 Likes

Z.ai just dropped GLM-Legal, an AI model built specifically for legal work. Think of it as a regular AI that went to law school and actually paid attention.

It runs on GLM-5.3-Flash and was trained on massive legal datasets, then practiced on tens of thousands of real legal task simulations. The result: it can actually complete legal tasks end-to-end, not just answer questions about law.

The headline number is a 19.2% all-pass rate on Harvey LAB, a strict benchmark covering 24 areas of legal practice. That tripled the base model's 6.7% score. It also costs just $0.15 per task, compared to $10.55 for Gemini 4 Argon.

Here's what you can build with it:

  • Contract review that flags risky clauses and suggests fixes
  • Evidence analysis across large document sets
  • Cross-border compliance planning

You can access it via API or try it inside AutoClaw, Z.ai's desktop agent app that turns goals into automated multi-step tasks. API access requires applying through their consultation page.

NVIDIA open-sources a voice model that listens and speaks at the same time
4,348 Likes

Old voice AI had a painful rhythm: you talk, it waits, it replies, you wait. PersonaPlex-7B kills that cycle entirely.

NVIDIA open-sourced a model that listens and speaks at the same time, just like a real conversation. No more awkward pauses. You can interrupt it, and it handles that naturally.

Here is what makes it worth your attention:

  • Runs on a single GPU (under 16GB VRAM), no server farm needed
  • Under 300ms latency, compared to 1.5-3 seconds with traditional voice pipelines
  • Beats Gemini Live and Qwen 2.5 Omni on conversation quality benchmarks
  • MIT license on code, commercially usable weights
  • You can define custom personas using text descriptions plus voice samples

Traditional voice AI stitched three separate tools together: speech-to-text, a language model, then text-to-speech. Each step added delay and lost emotional tone. PersonaPlex collapses all three into one model.

This opens up real-time voice agents, live customer support bots, and natural AI companions. Grab it on Hugging Face or GitHub.
