DeepSeek ships open-source Flash model with faster outputs and free search API
45,288 Likes

DeepSeek just dropped V4.1-Flash-1017, and it's a straight upgrade: faster, cheaper, and shorter outputs than the previous version. No tradeoffs.

The big idea? It uses a technique called reinforcement learning with self-feedback, meaning the model practices tasks, grades its own results, and improves. Think of it like a student who keeps retaking a test until they nail it. This makes it genuinely good at building full projects from scratch, not just answering questions.

Here's what's new and usable right now:

  • Model is open-source on Hugging Face and ModelScope
  • Search and Fetch APIs are now public at $0.75 per 1,000 calls
  • Works with Claude Code, Codex, and DeepSeek Harness (upgrade to v0.2.1-rc.1)
  • Search and Fetch calls via server-side tools are free for API users until Oct 31

The Search and Fetch APIs let your app pull live web data without building your own scraper. That's a big unlock for anyone building research tools or AI agents.

Anthropic's free scanner found 77 critical bugs in open-source projects in one week
8,010 Likes

Anthropic just launched OSS Scanner, a free tool that automatically hunts for security holes in open-source projects using its strongest AI models. Think of it as a tireless security intern that never sleeps and never misses a bug.

Here's the problem it solves: almost all software relies on open-source code, much of it maintained by small teams of volunteers. Those teams rarely have time for deep security audits. OSS Scanner fills that gap.

What you actually get per report:

  • A working proof-of-concept that reproduces the bug
  • A plain explanation of why it's dangerous
  • A suggested patch where possible

Early results: 77 critical and 803 high-severity findings already reported to maintainers. These included multiple vulnerabilities chained to unauthenticated remote code execution exploits.

To enroll, open a pull request adding a directory under projects/name with a project.yaml file containing your repo address and contact email. Anthropic verifies you're a core maintainer before accepting.

Open-source tool generates game audio locally in seconds, no API key needed
5,296 Likes

Audio Studio MCP is a free, open-source tool that generates background music and sound effects directly on your Mac. No cloud, no API key, no cost per generation.

The problem it solves: game audio and video sound design used to mean paid subscriptions or hunting royalty-free libraries. Now you just describe what you want in plain English.

Under the hood it runs Stable Audio 3 (Stability AI's audio model) locally on Apple Silicon. On an M1 Mac, a 60-second track generates in roughly 5 seconds after the model loads.

Here's what you can generate and export:

  • BGM, instrument loops, and sound effects from one sentence, up to 4 candidates at once
  • Edit existing clips: restyle, regenerate a section, or extend a track
  • Export as OGG, WAV, or FLAC for Godot or Unity, with loudness normalization baked in

To get started: paste the GitHub repo link into Claude Code and ask it to install and register the MCP server. Or manually run git clone then ./install.sh. Requires Apple Silicon with 16 GB RAM recommended. MIT licensed.
