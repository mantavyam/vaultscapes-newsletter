Claude Code desktop app now runs multiple coding sessions side by side
18,663 Likes

Claude Code's desktop app just got a serious upgrade for managing multiple tasks at once. Here's the deal.

You can now run parallel sessions (think: multiple tasks happening at the same time, each in its own tab). Claude spins up a separate mini-session for each task, then reports results back to your main session when done. Your main thread stays clean and readable.

  • Live to-do list inside each session, so you always see what Claude is doing
  • A recap card appears when Claude needs your input, no digging required
  • Save folder setups, SSH hosts, or cloud configs as reusable environments
  • Use /btw to ask a side question in a new tab without interrupting your main session
  • One-click follow-up sessions from Claude's own suggestions

This opens up running entire workflows in parallel without losing track of anything. Update the desktop app and start a new session to try it.

Open-source macOS tool brings fully local semantic search to photos, audio, and code
9,617 Likes

Your Mac has always been bad at finding files. You remember the moment, not the filename. DigUp fixes that.

DigUp is a free, open-source macOS menu bar app that lets you search your files by describing what you remember. It runs Google DeepMind's EmbeddingGemma 2 entirely on your machine. No cloud. No account. No data leaving your laptop.

The trick: it converts text, images, audio, and video into points in the same shared space. So one query can reach across all your file types at once.

Here's what you can actually do:

  • Type "dog near water" and find the photo
  • Type "where they talk about sleep" and jump to that podcast minute
  • Type "payment declined error" and surface the right screenshot
  • Search your codebase by what a function does, not what it's called

Hit Shift+Cmd+Space from anywhere. Requires Apple Silicon and macOS 14+. One-time 865 MB model download, then fully offline.

Google releases Gemini 4 Argon, cutting bad code commits by 30% in production
9,403 Likes

Google just dropped Gemini 4 Argon, its most capable coding model yet, and it's already been battle-tested inside Google's own production codebases. The results? A 35% boost in code written by AI agents and 30% fewer bugs making it past code review.

The big unlock here is output size. Argon can generate up to 1 million output tokens in one shot, up from 64K. Think of tokens as chunks of text. More tokens means the model can rewrite entire codebases, migrate legacy systems, or refactor hundreds of files without stopping mid-task.

Real things it has already done:

  • Helped Chrome engineers untangle a 40-million-line codebase, finishing months of work in weeks
  • Translated 40-year-old scientific code into Rust
  • Autonomously built a 3D Japanese pagoda in Blender using multi-agent looping

You can try it now in the Antigravity app or CLI, Google's agentic coding platform, if you're on AI Pro or Ultra. Install via curl -fsSL https://antigravity.google/cli/install.sh | bash, then run agy.
