Google DeepMind unveils Gemini 4 Argon with 1M token output for complex workflows
38,544 Likes

Google just dropped Gemini 4 Argon, its most powerful model yet. But here's the catch: you can't use it yet.

Right now it's only available to vetted cybersecurity defenders through the Fairwind Program, a limited-access channel for governments and trusted partners. Broader access for everyone else is coming soon.

So what makes it special? The biggest deal is the output limit. Previous Gemini models could write up to 64,000 tokens in one response. Argon pushes that to 1 million output tokens, meaning it can reason through massive, multi-step problems without stopping. Think full codebase migrations, long legal documents, or complex security audits in a single pass.

Here's what it can do:

  • Autonomously find, validate, and patch critical software vulnerabilities without human help
  • Handle real-world software engineering across 20 programming languages
  • Work through legal, financial, and enterprise knowledge tasks end to end

Pricing starts at $2 per million input tokens and $10 per million output tokens. Sit tight for general access.

OpenAI launches Ultrafast tier with 8x faster GPT-6 and new GPT-6.1 Sol model
8,427 Likes

OpenAI just dropped two things worth knowing about: a new model and a new speed tier.

GPT-6.1 Sol is the headline model. Think of it as Astra's smarter little sibling. It nearly matches GPT-6 Astra on agentic coding, computer use, and professional work at one-fifth of Astra's token prices. Call it via the API as gpt-6.1-sol.

Then there is Ultrafast, a paid speed tier. Tokens are the chunks of text the model generates. Normally that feels slow when a user is waiting. Ultrafast hits up to 300 tokens per second, with 8x faster generation in Codex and 6x in the API. That unlocks real-time feeling apps that were too laggy before.

To get Ultrafast in Codex and ChatGPT Work, you need the new Pro 500 plan. Pro 500 provides the highest included usage and is the only Pro tier that includes Astra Ultrafast.

  • GPT-6.1 Sol: $2 input / $10 output per 1M tokens
  • Ultrafast Astra API: $60 input / $300 output per 1M tokens
  • Pro 500: $500/month, 25x Plus usage, Ultrafast included

OpenAI ships major Codex CLI update with voice, parallel agents, and new UI
4,628 Likes

Codex CLI just got a serious upgrade, and if you live in the terminal, this one's for you.

The whole interface is now full-screen with way better readability. Your input box stays pinned at the bottom, so no more scrolling up just to type your next message. Old history loads as you scroll back, no limits.

The big new stuff:

  • /agents lets you see all running tasks, check progress, and jump between them
  • /fork splits your current conversation into a separate branch with its own code checkout, so you can try a different approach without losing your original
  • /voice lets you speak to Codex and hear it respond, right in the terminal
  • /usage for analytics, /theme for custom looks, Mermaid diagrams and LaTeX rendered inline, collapsible diffs

This opens up real parallel workflows: run multiple agents, fork ideas, track everything, without leaving your terminal. To get it now: npm install -g @openai/codex@latest
