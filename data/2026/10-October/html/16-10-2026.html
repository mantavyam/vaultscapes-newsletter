Meta releases 816B open-weight model built for coding and long agentic tasks
9,882 Likes

Meta just dropped Muse Spark Open, and it's a big one. It's a massive 816 billion parameter model, but here's the trick: only 42B parameters actually run per request. Think of it like a team of 256 specialists where only 8 show up per task. You get huge model quality without paying for all 816B every time.

What can you actually build with it?

  • Coding agents that handle long, multi-step tasks without losing track
  • Apps that read text, images, video, and audio all at once
  • Workflows using a 1M token context window, meaning you can feed it entire codebases in one shot

The wild part: you can run this locally on two Apple M5 Ultra Mac Studios using the MLX framework. No cloud required. You can also hit it via API on Groq, Together AI, OpenRouter, and others, or grab the weights on Hugging Face. Fine-tuning is supported through PyTorch. The license allows free use for many projects, but check the Muse Model License for commercial limits.

Cheng Lou's open-source tool converts JavaScript code into a real neural net without training
9,040 Likes

What if your regular JavaScript code was already a neural net? That's the idea behind Handwired.

Neural nets are usually trained on data, which makes them fuzzy and probabilistic. Handwired skips training entirely. Instead, it converts your if-else statements and loops directly into neural net weights, numbers that represent your program exactly, with zero guessing.

Why does this matter? Because now your code is fully differentiable, meaning you can apply machine learning techniques like loss functions and backpropagation (nudging numbers to improve a result) to actual working software.

  • Runs entirely in the browser, no GPU needed
  • Search 100k JSON files in real time using WebGPU matrix math
  • Photos that learn to rearrange themselves as you drag
  • Mix it with an LLM so it can follow both learned behavior and exact program logic

You can grab the source and tutorial on GitHub and play with the demos live in your browser right now.

OpenAI ships GPT-Live-1.1 with new voices in six languages to all users
8,941 Likes

OpenAI just updated its voice model. GPT-Live-1.1 is now live for all users across ChatGPT, Codex, and Dots.

The big deal? Voice now sounds actually local, not like a robot guessing at accents. It brings 13 new voices, two per language, in French, German, Hindi, Japanese, Korean, and Mexican Spanish, plus Bubbie in English.

There are also two model sizes now. Plus and above users get GPT-Live-1.1 by default, while others get the smaller Quip version.

What else changed:

  • More natural accents across languages, and the voice uses a wider range of short phrases when it is searching instead of repeating "checking..." on loop.
  • More natural handoffs when delegating tasks, and better steerability so the voice responds the way you actually want.
  • API access is coming, but OpenAI has not provided a date.

To try it now: open the ChatGPT app, tap the Voice icon, and pick Live mode from Settings then Voice.
