Anthropic renames Claude plans and drops 5-hour limit for verified Ultra subscribers
31,853 Likes

Claude just got a naming refresh. The Max 5x plan is now simply called Max ($100/month), and Max 20x is now called Ultra ($200/month). Same price, cleaner names. Nothing changes for existing subscribers.

The bigger news? The 5-hour usage limit is gone for verified Ultra accounts. That cap used to cut off heavy sessions mid-flow, which was frustrating if you were deep in a long coding task or running background jobs. Now you can run longer without hitting a wall.

A few things to know:

  • Newer accounts keep a temporary limit until verified, to prevent abuse. You'll get an email when it's lifted.
  • Weekly limits are still in place, unchanged.
  • If you're already verified, the removal is rolling out to you now.

Bottom line: longer uninterrupted sessions means you can tackle bigger tasks without getting cut off at a bad moment.

Developer rebuilds Apple's subvocal feature for AirPods Pro in 9 minutes with one prompt
9,792 Likes

A startup called Subvocal raised $1.3M to build glasses that turn silent mouthing into text at 200+ words per minute. No keyboard. No talking out loud. Just mouth words and they appear as text.

Then Joe Blau replied with a gut punch: he rebuilt the same idea in 9 minutes with one prompt, for AirPods you already own, and put it on GitHub for free.

Here is how his app, subvox, actually works:

  • Your AirPods have motion sensors for spatial audio. Subvox reads that head-motion data when you silently mouth words.
  • You train it by mouthing a word a few times. It stores those as templates, then matches future mouthing against them.
  • No AI model involved. Just pattern matching on motion signals.
  • To run it: brew install xcodegen, then xcodegen generate, then open in Xcode. Requires macOS 14 and AirPods Pro.

The bigger story: a funded startup took months to demo this. One prompt rebuilt it. Software ideas alone are not a moat anymore.

Vercel Labs ships open-source tool letting AI agents control your whole desktop
9,473 Likes

Most AI agents that control your computer work by taking screenshots and guessing where buttons are. Slow, expensive, and fragile. agent-desktop from Vercel Labs fixes that.

Instead of screenshots, it reads your OS's accessibility tree (think of it as a structured map of every button, input, and window on screen) and gives each element a stable ID called a ref. Your agent clicks the ref, not a pixel. No vision model needed.

Here's what you can do with it:

  • Let agents open apps, toggle settings, or inspect logs while you keep coding
  • Run multiple agents in parallel, each with its own cursor, on the same machine
  • Automate end-to-end desktop app testing without pasting screenshots into chat
  • Works with Claude Code, Codex, and any shell-capable agent

Install it: npm install -g agent-desktop. Free, open-source, Apache 2.0. Runs on macOS, Windows, and Linux.
