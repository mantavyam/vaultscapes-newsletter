Claude Code cuts background subagent token cost by 99% in v2.1.316
17,480 Likes

Claude Code just got a quiet but useful fix for background subagents, those helper agents that run tasks in parallel while your main session keeps going.

Here is the problem it solved. Every 30 seconds, each background subagent refreshed its status line. To do that, it re-read its entire conversation history each time. That is expensive. The longer the session, the worse it got.

Now, Haiku 5.5, a smaller and faster model, writes that status update from short notes instead of the full transcript. The result: each status update costs 99% less to generate.

What does that mean for you? More runway on the same plan.

  • Sessions with background subagents now use about 5% less of your usage limit
  • That translates to roughly 6% more prompts before you hit the wall
  • No config changes needed, just update to v2.1.316+ with claude update
  • Live for Pro, Max, Ultra, Team, and Enterprise users

Small change, real impact, especially if you run long multi-agent sessions.

OpenAI ships ChatGPT Images 2.6 with GIF output and 6-second image generation
13,311 Likes

OpenAI just dropped Images 2.6, and it is a solid upgrade worth knowing about.

The headline feature: you can now generate animated GIFs from a text prompt or a photo. You can tweak the speed and edit individual frames. The model keeps characters consistent across frames, so animations actually look coherent.

The other big addition is reference images. Save a character, a pet, or a product once, and reuse it across future creations without re-uploading anything. Huge for anyone building consistent visual content.

On the API side, two models are now available:

  • Flare (gpt-image-2.6-flare): speed-first, generates in as little as 6 seconds. Great for prototyping and high-volume pipelines.
  • Sunburst (gpt-image-2.6-sunburst): higher quality, more consistent edits. Built for polished output.

Both support image markup and SVG export, so you can pinpoint edits and pipe results directly into design workflows. Overall generation is 50% faster than before. Available now in ChatGPT, Codex, and the API.

Kimi.ai releases Kimi K3.1 Pro model weights to the public
6,681 Likes

Moonshot AI just dropped the weights for Kimi K3.1 Pro on Hugging Face, and it's a big deal for anyone who wants a powerful model they can actually run themselves.

So what is it exactly? A 2.8 trillion parameter open-weight model with a 1 million token context window, meaning you can feed it an entire codebase at once. It uses a Mixture-of-Experts setup, where only a slice of the model activates per task, keeping it efficient despite the massive size.

Here's what it's good at:

  • Full-project coding in Unreal, Unity, and Godot, plus 3D modeling in Blender and CAD
  • Finance work with hallucination down by 65%
  • Ranked #1 among open-weight models on Agent Arena, across productivity, coding, and chat

Platforms like Ollama, Nebius, and Databricks already support it, so you don't need to self-host. The weights alone are around 1.56 TB, so local runs need serious hardware.
