Anthropic's Claude Code now tests iPhone Duo foldable layouts in iOS simulator
9,727 Likes

Apple's iPhone Duo is a foldable iPhone, and building apps for it means testing multiple screen states: folded, open, half-bent. That used to mean clicking around Xcode manually. Not anymore.

Claude Code now runs the iPhone Duo simulator right next to your chat. You describe what you want to test, and Claude folds and unfolds the device itself, checking how your layout holds up at each position.

For existing apps, just ask Claude to prep it for Duo. It can install Apple's App Resizability skill, which scans your project for layout problems and proposes fixes. You approve, Claude applies them, then verifies on the simulator. No rewrite needed.

  • Requires macOS with Xcode 27.1 or later
  • Install the Xcode plugin: /plugin install xcode@claude-plugins-official
  • Plugin lets Claude build, run, render SwiftUI previews, and search Apple docs

This puts Swift editing, builds, simulator control, and visual checks all inside one session.

OpenCode ships Rust-rewritten browser tool that uses 25x less memory
6,041 Likes

OpenCode Browse just dropped v0.1.0, and it's a full rewrite in Rust. That matters because the old version was bloated: it needed Node.js, Playwright, and a pile of npm packages just to connect your AI agent to a browser.

The new numbers are hard to ignore:

  • 25x less memory used, dropping from ~190 MB down to 5.6 MB per session
  • 23x smaller binary, now just 4.3 MB instead of 53-64 MB
  • No more Playwright dependency, the whole thing is self-contained
  • Browser tools now exposed directly to your agent as MCP tools (think: actions your AI can call like functions)

What does this unlock? Your agent can now open a URL, scrape a list, loop over it, call your other tools, and keep going, all using your real browser with your logins already active. No headless browser setup needed.

It works with Claude Code, Cursor, Codex, Zed, and any MCP client. Install via the extension or CLI.

LiquidAI ships decision models that read, locate, and extract from text, images, and audio
3,360 Likes

Liquid AI just dropped d1.2 and d1.2-ultra, two models built for one thing: making decisions from any input you throw at them, text, images, or audio.

These aren't chat models. They take a question, look at your data, and return a structured answer with a confidence score. Think of it like a smart classifier you can actually trust.

Five new things you can now do:

  • Pull a specific value from a document, like an invoice total, and get "not found" if it's missing instead of a hallucinated guess
  • Find every matching passage in text, like all personal data in a note
  • Locate objects in images with bounding boxes, one or many
  • Estimate numbers with a confidence range
  • Pick every label that fits from a list, each with its own probability

The confidence scores are actually reliable. d1.2-ultra's calibration error is 0.8, meaning when it says 80%, it's right about 80% of the time. That lets you auto-route low-confidence results to human review.

Pricing: $0.02/1M tokens for d1.2, $0.042 for ultra. You only pay for inputs, zero output cost.
