Anthropic's Claude API now caches conversations server-side, cutting time to first token by 35%
7,068 Likes

Every turn in a long AI conversation, your app was resending the entire chat history to the server. Every. Single. Turn. For a coding agent running hundreds of requests, that ballooned to around 800 KB per request.

Anthropic just fixed that with Message Threads, now in public beta on the Messages API.

The server stores your conversation between turns. You send only new messages plus the previous response ID, and Claude starts replying faster. That 800 KB request? It drops to 1.8 KB.

  • Median time before Claude starts responding drops by 35% on requests with 500K to 1M tokens
  • Threads are encrypted in memory, never written to disk, and expire 5 minutes after the last request
  • To use it: add the thread parameter and beta header to your API requests
  • No extra cost, standard token rates apply

One catch: threads can expire, so you still need to keep your own conversation history locally as a backup. The bigger your context, the more you gain from this.

Claude generates a Studio Ghibli anime scene as a single HTML file with no assets
6,333 Likes

Fable 5.5 just one-shotted a full anime short film. No video model. No assets. Pure code.

Someone gave it a detailed Studio Ghibli-style prompt and it spat out a single self-contained HTML file with a giant robot waking up in a mossy forest, rising into a golden sky. The whole thing runs in your browser with zero dependencies.

Here is what the file actually does:

  • Film embedded as base64 MP4, decoded into a Blob at load time
  • Custom player with play/pause, seek bar, fullscreen, and sound toggle
  • Live film-grain overlay drawn on a Canvas element
  • Keyboard shortcuts built in: Space, arrow keys, M, F

The kicker? No image or video model was involved. Fable 5.5 wrote every frame procedurally in code. You can clone the repo at ChetasLua/moss-keeper, open index.html, and it works offline instantly.

Run the same prompt on Fable 5.1 and quality drops noticeably. This shows how fast the gap between model versions is growing for creative code tasks.
