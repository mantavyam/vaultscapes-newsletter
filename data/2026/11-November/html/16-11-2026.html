Claude Code desktop app now supports custom themes with animated backgrounds
23,490 Likes

Claude Code just got a glow-up. You can now build custom themes for the Claude Code desktop app using a feature called mods, which are small plugins that change how the app looks and behaves.

Want a dark purple background with animated particles? Just describe it to Claude and it builds the theme for you. No design skills needed.

Here is what you can do right now:

  • Change colors across the entire UI
  • Add animated backgrounds
  • Use the theme-examples plugin to get started fast with pre-built scenes
  • Write your own theme from scratch using the official docs

To try it, update to the latest desktop version. Themes currently work in local sessions only.

The fun part: you do not need to write a single line of CSS. Just tell Claude what vibe you want. It handles the rest. Your terminal, your aesthetic.

Anthropic upgrades Claude Code Projects with smarter coordination and thread sharing
21,615 Likes

Claude Code just got a solid upgrade to its Projects feature, and it changes how you manage complex, multi-part work.

Projects let Claude run multiple tasks at the same time in separate threads, like having several conversations going in parallel. The coordinator, the part that oversees everything, now speaks up more. It answers your questions directly in the project chat and gives you live status updates on what's running.

  • Share threads as read-only links with anyone signed into Claude
  • Set reminders on any thread so it hides until you need it, then Claude surfaces it automatically
  • /btw spins off a new thread mid-task so your current one stays focused
  • /fork branches a thread so you can try a different approach without losing your original
  • Artifact thumbnails now show inside each thread for faster navigation

Projects is in public beta on Pro and Max plans. Join the waitlist if you don't have access yet.

DeepSeek opens web search, file parsing, and voice to API developers
14,042 Likes

DeepSeek just gave its V4.1-Flash model a serious upgrade. The tools powering the DeepSeek consumer app are now available through the API. No more stitching together third-party services.

Before this, adding web search or PDF parsing to your AI app meant calling external APIs yourself and manually assembling the context. Until now, incorporating web search, PDF parsing, or speech recognition required setting up your own infrastructure. That changes now.

Here is what you can plug in with a few parameters:

  • Web Search: the model searches the web and returns cited answers automatically
  • Deep Thinking Search: searches and reads pages during multi-step reasoning
  • File Input: drop in PDFs, Office files, or images and the model reads them
  • URL Reading: paste a link in a message and the model fetches and reads it
  • Safety Checks: screens inputs and outputs, flags risky content automatically

Enable search with deepseek_web_search and URL reading with deepseek_read_url. Tool usage is billed on top of normal token prices. Public apps must have safety checks on.
