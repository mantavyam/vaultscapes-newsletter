Anthropic ships Claude Code feature that reviews and fixes your pull requests
17,936 Likes

You open a PR, then spend the next hour context-switching back to fix review comments. That loop is the real productivity killer. Claude Ship is here to break it.

It's a set of 3 agents that take your GitHub PR from review all the way to approval, without you babysitting it.

  • Code Review reads your diff and flags bugs, already live for everyone.
  • PR Steward (beta) watches the PR and pushes fixes for failing CI checks, merge conflicts, and reviewer comments automatically.
  • Claude Approvals (beta) reads a policy file you write in your repo and approves routine PRs that pass it, no human needed.

To try it: update Claude Code and type /ship. It commits, opens the PR, reviews it, and watches it for up to 7 days. Your branch rules still control what actually merges.

On Team and Enterprise, admins can enable it repo-wide so it runs on every PR automatically.

OpenAI and Cisco release open-source tool that lets agents patch Linux systems live
12,228 Likes

Every Linux server has a scary window: a vulnerability is found, but the patch isn't ready yet. Your system sits exposed. That's the exact problem Shirudo solves.

Built by Cisco and OpenAI, Shirudo is a free, open-source runtime that lets AI agents drop temporary security shields onto a live Linux system, no restart needed. Think of it as a bouncer blocking a specific door while you fix the lock.

The magic is eBPF, a Linux feature that runs tiny programs inside the operating system without touching its source code. Shirudo uses those programs as shields that block the exact path an attacker would use.

Here's what you can actually do with it:

  • Let AI agents scan for vulnerable systems and auto-generate shields
  • Test shields against real exploits before deploying
  • Deploy protections fleet-wide without disrupting running workloads
  • Try it locally via a VM quickstart on x86-64 or arm64

It's on GitHub under a BSD 2-Clause license. It doesn't replace patches. It just keeps the lights on until they ship.

Z.ai's GLM-5.4 loops transformer layers to code games, 3D shaders, and CAD models
11,201 Likes

Z.ai just shipped GLM-5.4, and the most interesting thing about it is how it gets smarter without getting bigger.

Normal AI models add more layers to reason better. GLM-5.4 takes a different path: it runs the same 28 layers twice. Think of it like reading a problem, drafting an answer, then re-reading the problem with fresh eyes before finalizing. Same brain, deeper thinking.

The result? A 750B-parameter model that Z.ai claims performs like models 3x its size.

What you can actually build with it now goes well beyond writing functions:

  • Video, games, and 3D shaders using code as the creative tool
  • CAD modeling and visual coding with the new built-in vision support
  • Long context tasks with a 1 million token context window

It is live now on the GLM Coding Plan with 50% more weekly quota than the previous version. API access and open weights are coming after safety review.
