Anthropic Turns Claude Artifacts Into Real Desktop Apps With One Click
▲ 46,629 Likes

Claude just let your AI-built tools escape the chat window. "Install as app" is now in beta, and it does exactly what it sounds like: any Claude artifact becomes a real Mac or Windows desktop app with its own icon, its own window, and real OS features.

No packaging. No code signing. No API key setup. You describe your app to Claude, test it as an artifact, then hit "Install as app" from the Share menu. Done.

Here's what these apps can actually do:

  • Send desktop notifications and register global keyboard shortcuts
  • Live in your Mac menu bar or Windows system tray
  • Connect to external services through Claude connectors
  • Read, modify, or run files locally with full computer access (your apps only)

One catch: apps need an active internet connection and a signed-in Claude session to open. Also, every update resets permissions, so users re-approve access each time. Anthropic does not review apps before install, so that responsibility lands on you.

Anthropic Expands MCP With Skills, Background Tasks, and Direct File Transfers
▲ 8,203 Likes

MCP, the open standard that lets AI connect to external tools and data, just got four big upgrades. Here's what changed and what you can now build.

Skills let your MCP server ship step-by-step instructions alongside its tools. Think of it like sending a recipe with the ingredients. Claude loads the skill only when needed, so it doesn't eat up memory. Updates go live server-side, no reinstall required.

  • Tasks: run long background jobs (research, pipelines, agent loops) without blocking Claude. It keeps working and picks up results when ready.
  • Elicitation: pause mid-workflow to ask the user for approval before spending money or deleting data. Supabase and Railway already use this.
  • File Uploads: send PDFs, spreadsheets, and images directly to your server, skipping the context window entirely. Cuts memory waste on large docs.

Tool search also now cuts context usage by over 85% in multi-server setups. Skills are live in beta for Pro, Max, and Ultra plans today.

OpenAI's GPT-6.2 Designs Real Proteins That Bind Drug Targets in the Lab
▲ 6,694 Likes

Designing proteins used to need a whole team of specialized AI tools. One for structure, one for sequences, one for docking. Now GPT-6.2 handles all of that through plain prompts and Python code it writes itself.

OpenAI tested this with a biotech partner in actual lab experiments, not just simulations. The results:

  • Out of 322 candidates, 35 bound their targets across five different proteins including PD-L1, a key cancer immunotherapy target
  • In a second test, 14 of 107 proteins bound their targets using sequences GPT-6.2 designed from scratch
  • For antibody redesign, 70% of redesigned fragments kept their binding ability after modification
  • On molecule docking benchmarks, it hit 93% accuracy, beating the previous best of 50%

What this opens up: you can describe a protein constraint in plain English, let the model generate candidate structures as code, then filter and test the best ones. No specialized ML training required.

Big caveat: full protein structure prediction is still weak compared to tools like ESMFold2. And binding in a lab dish is not the same as a working drug. Independent review is pending.
