OpenAI ships GPT-6.2 Astra and Sol at one-third the cost of GPT-6
46,727 Likes

OpenAI just dropped GPT-6.2 Astra and Sol, and the headline is simple: more capable, cheaper to run.

Here is the quick breakdown. Astra is the heavy-hitter for complex work. Sol is your everyday workhorse. Think of them as a sports car vs. a reliable daily driver.

  • Astra costs less than 1/3 the price per task compared to GPT-6 Astra, with API tokens priced 20% lower at $8 input / $40 output per million tokens.
  • Sol approaches Astra's coding performance at roughly one fifth of the cost, keeping the same $2 input / $10 output pricing.
  • Astra jumped 22 points on cybersecurity benchmarks and is the first externally released model rated High for AI self-improvement, meaning it can meaningfully help accelerate AI research itself.
  • Both models handle multistep agentic workflows, where the AI completes a chain of tasks automatically without you babysitting each step.

To use them, hit gpt-6.2-astra or gpt-6.2-sol in the OpenAI API. Available now for Plus, Pro, Enterprise, and Edu users in ChatGPT Work and Codex.

Anthropic's experimental Claude Code mode chains tools and answers mid-run
6,247 Likes

Claude Code just got a new experimental mode called Code Mode, and it changes how Claude uses tools under the hood.

Normally, Claude calls tools one at a time: run Bash, wait, read the result, call the next tool, wait again. It's slow and chatty. Code Mode fixes that.

With Code Mode on, Claude writes a small JavaScript program that chains all your tool calls together. That script runs in your session, collects only the useful output, and hands Claude a clean summary. You can also get answers while long commands are still running.

  • Run multiple tools in parallel, not one by one
  • Get responses while commands are still executing
  • Scripts time out after 10 minutes max
  • Terminal only, does not work in VS Code or the Desktop app

To try it: run CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1 claude, confirm the prompt, and you're in. To make it permanent, add the env variable to ~/.claude/settings.json.

OpenAI gives four outside safety teams deep access to probe its models
4,323 Likes

OpenAI just invited four independent safety teams to dig deep inside its models and look for problems. This is called an embedded assessment, meaning outside experts get real access to internal systems, not just the public API.

Here is what each team is hunting for:

  • Apollo Research checks if the model could secretly work against the people building it, like an AI quietly resisting its own oversight without anyone noticing.
  • METR digs into the biggest reinforcement learning training run to find bad behaviors that OpenAI's own tests may have missed.
  • Transluce audits how good the safety tests actually are, then recommends what is missing.
  • Goodfire uses tools to look inside the model's internals during training to spot and fix unsafe patterns.

The honest catch: Apollo says access is still limited and does not yet meet its bar for a full evaluation. Still, this opens a path toward real third-party accountability in AI development.
