Claude Code remote control gets faster reconnects and phone-to-machine session start
16,701 Likes

Claude Code's Remote Control just got a serious reliability upgrade. If you've ever had your phone and laptop fall out of sync mid-session, that frustration is mostly gone now.

Here's what actually changed:

  • Auto-reconnect: close your laptop, switch wifi, whatever. It reconnects on its own.
  • Start sessions from your phone: any machine running claude remote-control shows up as a device card. Tap it, pick a folder, and it fires up on that machine.
  • Slash commands on mobile: /clear, /compact, and /diff now work properly from your phone.
  • Live sync: model, effort level, and session state stay matched between devices. No more stale sessions hanging around after Claude Code exits.

What this opens up is real: you can kick off a coding session from your couch, walk to your desk, and pick it up without skipping a beat. Update your CLI, Desktop, and mobile apps to get all of this.

DeepSeek ships vision model that rivals Claude on multimodal agent benchmarks
12,828 Likes

DeepSeek just shipped V4-Flash-Vision-Exp, a new model that can see. It takes the already solid V4-Flash and adds image understanding, so your agents can now read screenshots, charts, and documents, then act on them.

On agent benchmarks requiring visual understanding, it delivers a significant leap over V4-Flash, bringing multimodal agent capabilities close to Opus-4.8. That's a top-tier competitor, at Flash pricing.

Here's what you get out of the box:

  • Set model='deepseek-v4-flash-vision-exp' and you're in. DeepSeek Harness 0.1.1 ships with support built in.
  • Images are billed at a per-image cap of 384 tokens, with pricing identical to V4-Flash.
  • Supports Chat Completions, Messages, and Responses. Mix images and text, passing images as base64, external URLs, or Files API references.
  • The Files API is free. Upload an image once, get a file_id back, and reuse it across requests without re-uploading every time.

The model accepts images alongside text through the same API endpoint you already use for V4-Flash, with no price premium. Vision at Flash prices is the real unlock here.

Anthropic upgrades Claude Security scans with its most capable model in public beta
11,255 Likes

Anthropic's most powerful security model was previously locked away, available only to a small vetted group. Now it's open to all Claude Enterprise customers, no special access needed.

Claude Mythos 5 now powers Claude Security scans. Point it at a GitHub repo and it traces data flows across files, understands how components talk to each other, and catches bugs that basic pattern-matching tools miss entirely.

Each scan returns:

  • A CWE category (a standard label for the type of weakness found)
  • Confidence and severity ratings so you know what to fix first
  • A suggested patch you can open directly in Claude Code and approve

You never talk to Mythos 5 directly. It runs behind the scan and hands back results only, so it cannot be steered into writing exploits. Scans bill as standard token usage under your existing plan.

Anthropic also launched the Defender Advantage Fund, putting $35M in credits toward patching open-source vulnerabilities. Big picture: powerful security tooling is getting cheaper and more accessible fast.
