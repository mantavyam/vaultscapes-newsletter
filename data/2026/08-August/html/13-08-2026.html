xAI ships Grok 4.6 at half the price of rival frontier models
36,532 Likes

Grok 4.6 just dropped, and the story here is simple: top-tier performance at half the price of the competition.

The model is built for long, multi-step tasks. Think digging through a codebase, researching a topic across many steps, or taking a rough idea all the way to a working app. It focuses on long-running agents and ambitious interactive and visual work, staying with complex tasks across many steps.

Here is what matters:

  • Pricing: $2/M input, $6/M output tokens. That is roughly 60% below GPT-5.6 Sol's $5/$30.
  • 500K token context window, enough for large codebases.
  • Function calling, structured outputs, web search, code execution, plus text and image input.
  • A faster variant is available at double the price for lower latency.

It is strongest on knowledge work and legal reasoning, with price-to-intelligence as its main pitch. Not the best at everything, but very competitive for the cost.

You can use it now via the API with model string grok-4.6. Cursor and Grok Build are offering 2x included usage for the first week.

DeepSeek ships V4-Pro with smarter agents and 50% off-peak API pricing
11,029 Likes

DeepSeek V4-Pro just hit general availability, and the headline is simple: it is now the model you actually call in production, not a preview.

Here is what changed and why it matters:

  • 1 million token context window -- that is an entire codebase or a long multi-turn agent session, no chunking needed.
  • 384K max output -- huge for code generation tasks that produce long files.
  • Flexible reasoning effort: set it to low for quick answers, high for complex agent workflows. You control how much the model thinks before responding.
  • Native Responses API support with one-click Codex setup. The Responses API is OpenAI's format for building coding agents -- DeepSeek now speaks that language natively.
  • Off-peak pricing is 50% cheaper than peak rates, so you can schedule heavy workloads overnight and cut costs significantly.

You can try it now via "Expert Mode" on the web or app, or hit the API directly. Model names are unchanged, so no migration needed.

Anthropic syncs Claude browser sessions across desktop, web, and mobile
10,292 Likes

Claude's Chrome side panel used to run in total isolation -- what you did in the browser stayed in the browser, invisible to your other devices. That split is now gone.

The Chrome extension is now a full Cowork session. Here's what travels with you:

  • Conversations save to your history, and skills and connectors work in the browser.
  • Claude can see the page you're on and take actions -- clicking links, typing text, navigating pages, and filling out forms using your existing logins.
  • You can collect invoice details from vendor portals in the browser, then continue the same session on desktop to add local files or compare results.

One real risk: prompt injection, where a malicious website hides instructions inside page content to hijack Claude's actions. Anthropic warns browser agents remain vulnerable -- a separate check reviews consequential actions, and Claude still asks before purchases or sharing personal data.

Max and Team get access today, with Pro rolling out over the coming weeks.
