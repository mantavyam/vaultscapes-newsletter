Prime Intellect releases open-source coding agent that scores 95.5% on ARC-AGI-3
8,864 Likes

Prime Agent just dropped, and it's worth paying attention. It's an open-source coding agent that wraps around AI models and makes them dramatically smarter at long, complex tasks.

Here's the key idea. Most AI tools forget everything between steps. Prime Agent doesn't. It runs inside a persistent Python environment where context carries over from one step to the next. Think of it like giving the AI a sticky notepad that never gets erased.

What you can actually do with it:

  • Spin up sub-agents for delegated tasks and modify its own approach based on what's working
  • Use the /refine command to let the agent update its own prompts, memory, and skills mid-task
  • Run sub-agents as full independent sessions that survive terminal disconnects via a background daemon

The results speak: with Opus 5, it hits 95.5% on ARC-AGI-3, surpassing the human expert baseline. It also uses fewer tokens than competing tools by running functions over data instead of reading it.

It's fully MIT open-source, free to use with your own API keys, and works with both open and closed models.

mattpocock/skills v1.2 just dropped, and it's now the 19th most-starred repo of all time with 13.5 million downloads. If you haven't used it, skills.sh gives your AI agent a set of reusable commands that make it smarter at specific tasks.

The biggest addition is full docs. Every skill is now explained with flows and troubleshooting. You can also install it directly from Claude's official marketplace, and Codex is now fully supported.

Here's what changed and what it unlocks for you:

  • /prototype now outputs HTML instead of a terminal UI, so you can share logic prototypes with anyone, not just people with a terminal

  • /to-questionnaire turns a tough question into a shareable doc you can walk through with a teammate
  • /wait-what simplifies confusing model output into plain language you actually understand

Meta ships Muse Code, a terminal coding agent that runs 1,000+ tool calls autonomously
3,041 Likes

Meet Muse Code, Meta's new terminal coding agent. Think of it like a tireless coding partner that lives in your terminal, handles entire repos, and keeps working even when you walk away.

Here's what makes it different from just asking an AI to write code: it runs persistent background agents, meaning multiple mini-agents work in parallel on your task simultaneously, so complex jobs finish faster with less hand-holding from you.

  • Plans, writes, and validates multi-file changes across large repos
  • Crash-safe: a local log records every action, so it resumes exactly where it stopped
  • Understands video input, like turning a home walkthrough mp4 into a full booking website
  • Scored 82.9% on Terminal-Bench 2.1, just behind Claude Opus 5
  • Available on macOS and Linux via the Meta Model API

Install it with one command: curl -fsSL https://dev.meta.ai/install.sh | bash
