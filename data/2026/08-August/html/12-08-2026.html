Anthropic's unreleased Claude model pushes Riemann hypothesis progress from 41.6% to 67.2%
16,928 Likes

Someone told Claude to take a real stab at one of math's hardest unsolved problems. Claude failed. But what it found on the way down is interesting.

The Riemann Hypothesis is a 160-year-old math problem about where a special function hits zero. Think of it like a treasure map where all the X marks should land on one specific line. Nobody has proven they all do. The best humans could do was prove that at least 41.6% of those X marks land where expected.

Claude just pushed that to 67.2%, the biggest single jump in history on this problem. It did this by treating the zeros as one unified space instead of analyzing them separately.

  • Used 60 AI subagents running in parallel inside Claude Code
  • Tried 650 failed ideas before finding the approach that worked
  • Ran 2,400 shell commands over a day and a half
  • Proof verified in Lean 4 and reviewed by two external math experts

The proof code and process logs are all public. The model is unreleased, but the agent architecture is yours to study today.

OpenAI ships GPT-5.6-Cyber, a model that found zero-days in Chrome's V8 engine
9,319 Likes

OpenAI just split its Daybreak cybersecurity program into two tiers, and the difference matters a lot depending on what you're building.

Daybreak Blue is the starting point. You get GPT-5.6 Sol with security guardrails loosened just enough for defensive work. Think of it as the standard model, but it won't refuse you when you ask it to analyze malware or review vulnerable code.

Daybreak Red is the serious tier. It unlocks GPT-5.6-Cyber, a model specifically trained to do the risky stuff: finding zero-day vulnerabilities (unknown security holes), building exploit chains, and validating attacks. It completed 95% of advanced security tasks in testing, versus just 1.5% for the regular GPT-5.6.

  • Blue: vulnerability discovery, malware analysis, code review, incident response
  • Red: exploit development, zero-day research, security testing
  • Real proof: it found two unknown bugs in Chrome's V8 JavaScript engine

Red access requires approval. You apply, get vetted, then get monitored. Not open to everyone yet.

NVIDIA releases open 30B model that runs 4x faster than similar-sized models
3,469 Likes

NVIDIA just dropped Nemotron 3.5 Lightning, and the story here is speed without the usual tradeoff.

Most AI agents waste compute. They use a massive, slow model for every single step, even boring ones like calling a tool or checking a result. Lightning fixes that.

Here is the trick: it has 30B total parameters but only activates 3B at a time. Think of it like a team of specialists where only the right people show up for each task, instead of the whole company attending every meeting. That is the MoE (Mixture-of-Experts) design.

The numbers back it up:

  • 4x faster output than similar-sized models
  • 86% accuracy on PinchBench, completing 10,000 tasks 35% faster than Qwen3 35B
  • 1M token context window for long agent sessions
  • Runs on a single H100 or DGX Spark

You can fine-tune it on your own data using NVIDIA NeMo for domains like cybersecurity, coding, or legal work. Weights are open on Hugging Face, deployable via vLLM or SGLang today.
