DeepSeek launches V4-Flash API with stronger agent skills and Codex support
32,653 Likes

DeepSeek just pushed V4-Flash into public beta, and the story here is not a bigger model. Same architecture, same size as the preview. They just retrained it, and the numbers jumped hard.

The agent scores now beat the higher-tier V4-Pro-Preview across all nine benchmarks. We're talking about a lighter model outrunning its own bigger sibling on real coding tasks:

  • Terminal Bench 2.1: 82.7 vs 72.1 for V4-Pro-Preview, nearly matching Anthropic's Opus-4.8 at 85.0
  • DeepSWE: 54.4 vs 7.3 for the preview
  • DSBench-FullStack: 68.7 vs 37.0 for the preview
  • Native Responses API support plus full Codex integration, out of the box

To use it, just set your model to deepseek-v4-flash. No URL changes, no auth changes. If you were already calling this endpoint, you got the upgrade automatically.

Note: scores are vendor-reported, not independently verified yet. V4-Pro API and the web app are still unchanged.

Open-source Rust tool classifies PDFs in 20ms, no OCR needed
10,378 Likes

PDFs have always been a pain for AI agents. You send one through OCR (a slow process that reads text from images), and you wait seconds per page. Firecrawl just shipped pdf-inspector to fix that.

The trick: not every PDF needs OCR. About 54% of PDFs are already text-based, like reports, invoices, and research papers. pdf-inspector checks which type you have in roughly 20ms, then skips OCR entirely for text-based files and only sends scanned pages through the slow path.

What you get out of it:

  • Clean markdown with correct reading order, tables, and formulas preserved
  • 200 PDFs processed in under 5 seconds, faster than every competing tool
  • Works in Python, Node.js, Rust, or the CLI
  • No external services, no GPU needed for text PDFs

You can drop it in with pip install pdf-inspector or npm install @firecrawl/pdf-inspector. It is fully open source under MIT.

Qwen releases 2.4T parameter model that codes autonomously for 10+ days straight
5,509 Likes

Alibaba just dropped Qwen3.8-Max, a massive 2.4 trillion parameter model built to handle real, long-running tasks on its own. Think of parameters as the model's "brain cells" -- more means more capacity to reason and plan.

Here's what makes it different from typical AI models:

  • It ran 10+ days of autonomous coding -- starting from an empty folder and shipping production code with zero hand-holding
  • It handles text, images, video, and documents all in one model -- and uses what it sees to check and fix its own work
  • It ran 500+ rounds of chip design optimization and a full year of e-commerce planning, all on its own
  • API-compatible with both OpenAI and Anthropic protocols, so you can point existing tooling at it without a rewrite

You can access it now via Alibaba Cloud's API. Pricing sits at $2/M input tokens and $6/M output, with cached input dropping to just $0.25/M. Open weights for Qwen3.8-Max and the smaller Qwen3.8-27B are coming next week.
